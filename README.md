# 💳 TkYD-BankSlipsSearch (v5.5.3)

**TkYD-BankSlipsSearch** — это легковесный, быстрый и автономный программный комплекс для кассиров и бухгалтеров, предназначенный для моментального поиска банковских слипов (чеков) эквайринга. 

Разработано специально для интеграции с ПО **SoftLand Systems "SLS-Эквайринг"**.

---

## 🔥 Главные фишки

- ⚡ **Моментальный поиск:** Вместо долгого шуршания по дискам программа использует локальную базу данных **SQLite3**. Поиск по тысячам чеков занимает доли секунды.
- 🔄 **Умное фоновое индексирование:** Программа сама сканирует папки с логами в фоне, не вешая интерфейс кассира.
- 🕒 **Всегда свежие данные:** Перед каждым поиском утилита мгновенно проверяет только сегодняшнюю папку, чтобы свежие транзакции сразу падали в выдачу.
- 🛠️ **Полная автономность:** Не требует интернета, серверов и сложных настроек. Запустил — работает.
- 🧠 **Автоопределение ОС:** Красивые эмодзи-иконки для современных Windows 10/11 и аккуратный текстовый режим для старой доброй Windows 7/8.

## 🚀 Горячие клавиши для кассира (UX на максималках)

Чтобы кассиру не пришлось страдать и переписывать цифры руками:
- 🖱️ **Двойной клик** по строке — скопировать **RRN** в буфер обмена.
- ⌨️ **Shift + Двойной клик** — скопировать **Код авторизации (К/А)** в буфер обмена.
- ↩️ **Enter** в поле ввода — запуск поиска.
- 📋 **Ctrl + V** (или правая кнопка мыши) — умная вставка из буфера, которая работает даже при русской раскладке клавиатуры.

## 🔍 По каким параметрам можно искать?

Поисковая строка всеядна. Вы можете ввести:
1. **Номер карты** (или последние 4 цифры)
2. **Сумму чека** (в рублях)
3. **Уникальный номер ссылки RRN**
4. **Код авторизации (К/А)**

Программа сама поймет, что вы ввели, подсветит тип совпадения нужной иконкой (`💳`, `💲`, `🔗`, `🔑`) и отсортирует результаты от самых свежих к старым.

## ⚙️ Настройка и Конфигурация

При первом запуске программа автоматически создает файл настроек `config.ini` в своей папке.

Пример содержимого `config.ini`:
```ini
[SETTINGS]
# Путь к папке, куда SLS-Эквайринг складывает ежедневные отчеты
reportsdayspath = ..\..\SLS-Acquiring\ReportsDays
# Глубина поиска в месяцах (чтобы не хранить в БД логи за мамонтов)
search_period_months = 12
```

> 💡 **Важно:** Путь к папке чеков может быть как относительным, так и абсолютным.
